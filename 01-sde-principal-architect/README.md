# 1. SDE and principal architect

This track is for principal-architect interviews from a senior Java and Spring Boot background. Each topic is split into a study note and a separate interview question file. Diagrams use dotted arrows for async calls, caches, and optional paths.

Suggested order:

1. Java language, collections, concurrency, JVM, and Java 8–17.
2. Spring Boot, REST and OpenAPI, JPA and Hibernate, Spring Cloud.
3. Testing, observability, and DevSecOps.
4. React, from UI code through architecture a backend lead can review.
5. Kubernetes, Kafka, RabbitMQ, and when to pick each broker.
6. Oracle, PostgreSQL, Redis, Cassandra, and polyglot persistence.
7. AWS, API resilience, the omnichannel POS design, and principal-level craft.

Fill story brackets in the principal-architect notes with your own incidents. Do not invent metrics.
