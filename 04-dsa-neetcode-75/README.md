# 4. NeetCode 75 (Blind 75 set)

These 75 problems are the set NeetCode hosts as Blind 75, in NeetCode’s topic order. Each problem has a study file (analogy, diagram, walkthrough, Java, and Python) and a separate interview Q&A file. Pattern files sit at `00-` in each folder.

Work in numeric order from 01 through 75. Say the analogy out loud, then close the note and write both languages.

| # | Topic folder | Problems |
| --- | --- | --- |
| 01–08 | Arrays and hashing | duplicate through longest consecutive |
| 09–11 | Two pointers | palindrome, 3Sum, container |
| 12–15 | Sliding window | stock, substring, replacement, minimum window |
| 16 | Stack | valid parentheses |
| 17–18 | Binary search | rotated minimum and search |
| 19–24 | Linked list | reverse through merge k |
| 25–35 | Trees | invert through serialize |
| 36–38 | Tries | trie, wildcard search, word search II |
| 39 | Heap | median from stream |
| 40–41 | Backtracking | combination sum, word search |
| 42–45 | Graphs | islands through course schedule |
| 46–48 | Advanced graphs | components, valid tree, alien dictionary |
| 49–59 | 1D dynamic programming | stairs through jump game |
| 60–61 | 2D dynamic programming | unique paths, LCS |
| 62 | Greedy | maximum subarray |
| 63–67 | Intervals | insert through meeting rooms II |
| 68–70 | Matrix | rotate, spiral, set zeroes |
| 71–75 | Bit manipulation | popcount through sum without plus |
