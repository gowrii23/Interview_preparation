# 2. ML, LLMs, and agentic AI

This track is for applied AIML interviews, including Indic-language and agentic roles such as Sarvam AI. Study notes teach the idea. Interview files hold sample answers. Recheck Sarvam’s public site before a conversation so model names stay current.

Suggested order:

1. ML foundations, transformers, and LLM internals.
2. LoRA, QLoRA, and practical PEFT.
3. Prompting, evaluation, and alignment (SFT, RLHF, DPO).
4. RAG, MCP and tool use, agentic systems, and production LLM boundaries.
5. Indic-language issues, ML system design, and the project story bank.

The story bank uses only the defect-triage agent and the Agentic Universe platform. Metrics stay in brackets until you add real numbers.
