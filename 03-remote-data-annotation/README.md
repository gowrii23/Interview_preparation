# 3. Remote AI training and data annotation

This track prepares for expert contracting and labeling work on Mercor, Alignerr (often typed as “Aligner”), and similar data-annotation platforms. It covers the craft: guidelines, preference labeling, code review of model output, and rubrics. It does not describe how to cheat an assessment.

Suggested order:

1. How remote AI-training work is structured.
2. Mercor and Alignerr, then recheck their current application flow.
3. Annotation craft, RLHF preferences, code-evaluation tasks, and rubrics.
4. How to present a backend-plus-AIML profile without overselling research.
